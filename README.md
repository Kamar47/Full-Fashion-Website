# Full Fashion – Clothing Store Website

## About the Project
Full Fashion is an academic web development project
that demonstrates an interactive online clothing store.

The website allows users to browse clothing collections,
view product details, select clothing sizes, and choose items.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Interactive clothing collections
- Product images and descriptions
- Clothing size selection
- Product selection
- User-friendly interface

## How to Run
1. Download or clone the repository.
2. Open `index.html` in a web browser.

## Project Type
Academic group project.
